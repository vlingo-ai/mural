# Phase 5.5B 资源清理摘要 — 2026-09-23 至 2026-09-24

用户授权清理本阶段 VPS、Mac mini 和 GitHub 上的冗余备份、临时文件及已合并分支。此文件只保留适合进入仓库的结果摘要；逐文件恢复清单、私有路径、备份标识和校验值由操作者在仓库外保存，不随公开文档发布。

## 范围与结果

- 删除前逐一核对分支的合并状态、原提交、开放 PR 和 worktree 占用；清理本地分支 27 个、远端分支 17 个。主线提交、开放 PR、发行版、注册表镜像和历史 CI 证据未删除。
- Mac 上 15 个旧文件、VPS 普通用户目录中 11 个旧文件移入各自受限的可恢复回收目录，未永久擦除。当前备份、恢复密钥、部署配置与运行数据未移动。
- VPS 正式备份目录中七份冗余加密备份移至受限回收目录；四份必要恢复点保留，并与 Mac 副本核对 SHA-256。Mac 副本通过 age 解密管道和 gzip 完整性检查；未落地明文 SQL。完整 PostgreSQL 恢复演练未执行。
- 精确删除九个不再需要的旧 Docker 镜像，未执行全局 prune。另一个镜像仍由成功退出的迁移容器引用，故保留；当前运行镜像、最近回滚候选、数据库卷、构建缓存和日志证据未清理。
- 清理后复核五个运行服务、公网健康接口及部署工作区；没有重启容器、执行迁移或发起付费会话。未测量实际磁盘释放量，因此不宣称释放了特定容量。

## 保留与恢复规则

清理不等于批准直接回滚到旧安全配置。恢复前须通过仓库外的私有清单核对目标、校验值和当前状态；仅在原路径不存在时恢复，绝不覆盖现有配置或数据。保留的回滚配置也不能整份覆盖当前配置。任何新一轮部署仍须按发布验证方案重新确认活动会话、加密备份、当前及回滚镜像、数据库迁移与非计费健康检查。

相关发布门禁见 [发布上线测试与验证方案](release-verification-plan.md)。
